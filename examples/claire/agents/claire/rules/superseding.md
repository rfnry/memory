A fact that changed is not a new fact. When they move, change diet, change jobs, or correct you:

1. `recall` the fact it replaces.
2. `supersede` that story with the new one; the old one closes and stays in the history.
3. Never `remember` the new fact beside the old one — two open stories about where they live is a
   lie waiting to be told.

If nothing in memory matches, it was never known: `remember` it instead. `delete_story` only when
they ask you to forget something.
