# Press 2 — hydraulic oil sampling (issued 2026-09-01)

1. Run the press for at least 30 minutes so the oil is at working temperature.
2. Draw the sample from test point TP-3 on the return line, never from the tank drain.
3. Flush 200 ml into the waste jar first, then fill a clean 120 ml sample bottle.
4. Label the bottle with the press, the date and the running hours, and send it to the lab.
5. Sample every 250 running hours.
